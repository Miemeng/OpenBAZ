# 《大巴扎自走棋》（The Bazaar）规则与设定总结

> 整理时间：2026年10月。游戏仍在持续更新，具体数值以当前版本为准。

## 一、游戏概况

- **名称**：《The Bazaar》，中文通称《大巴扎》/《大巴扎自走棋》。
- **开发商**：Tempo，由前《炉石传说》职业选手、知名主播 Reynad 发起制作，耗时约 7 年。
- **类型**：自走棋 + 卡牌/物品构筑 + Roguelike 事件选择 + **异步 PvP**。
- **平台与收费**：2025 年 8 月 13 日登陆 Steam，由免费模式转为买断制（Premium）。本体包含凡妮莎、皮格马利翁、杜利三名英雄，首发价 $39.99；后续新英雄以 DLC 形式出售（约 $19.99/个）。早期注册的老玩家可免费获得部分英雄。
- **核心特色**：异步对战——你对抗的是其他玩家在同阶段留下的"影子"阵容，兼具 PvP 的策略博弈，又没有实时对战的等待与挫败感，且可随时暂停。

## 二、对局流程：天数与小时

一整局游戏以"天"为大周期，以"小时"为行动点：

1. **每天包含若干个小时**（通常为 6 个）。每小时结束时，玩家从 **3 个选项中三选一**：进入商店购买物品、参加随机事件、获取某类型物品等。
2. **每天第 3 小时固定为野怪战**：从 3 只野怪中三选一挑战（PvE）。即使打输也能获得经验和金币（根据野怪强度和造成的伤害结算 1~4 点经验）；打赢还会随机掉落该野怪的独有技能或物品。
   - 野怪分青铜（同级，基本稳赢）、白银（高一级，较容易）、黄金（高两级，有挑战）、钻石/地狱级（除非构筑极强否则几乎不可能战胜）。
3. **每天的最后是 PvP 战斗**：与匹配到的其他玩家镜像阵容进行异步对战，战胜记 1 胜，战败扣除声望。
4. **经验与升级**：完成行动获得经验，攒满 8 点升级，升级时可选一个技能或升级一件物品。

整体流程可概括为：**选 2 个事件/商店 → 打野怪 → 再选 2 个事件/商店 → 与其他玩家镜像对战**，如此循环 10 天以上。

## 三、胜负与声望系统

- **声望（Prestige）**：相当于生命值的局外资源，初始 **20 点**。每次战败扣除**等于当天天数**的声望（第 3 天败北扣 3 点，依此类推）。
- **续命机制**：第一次声望耗尽时，声望锁定为 1，玩家可进行三选一决策强化自身，继续游戏；**第二次耗尽时游戏结束**，进入结算。
- **胜利目标**：
  | 胜场 | 结算 |
  |---|---|
  | 4 胜 | 青铜胜利 |
  | 7 胜 | 白银胜利 |
  | 10 胜 | 黄金胜利 |
  | 满声望 10 胜 | 钻石胜利 |
- 平局也计为胜利；胜场可兑换宝箱（皮肤、卡背等外观奖励）。模式分普通（对手较弱，适合练习）与排位（青铜到传说段位）。

## 四、棋盘与卡牌（物品）系统

### 1. 棋盘空间

- 玩家最多拥有 **10 格**构筑空间。开局只有 6 格，第 2、3 天各增加 2 格。
- 卡牌分**小型 / 中型 / 大型**，分别占 **1 / 2 / 3 格**。空间有限，如何取舍是核心策略之一。

### 2. 卡牌品质与游戏节奏

- 卡牌按品质分为**青铜 → 白银 → 黄金 → 钻石**，强度递增；部分卡只在高品质出现，但每张卡都能升至钻石。
- 节奏控制：开局只能拿到青铜级（多为辅助/经济卡）；第 2~3 天起出现白银级（部分可作核心终端）；第 5 天后出现黄金级；第 8 天后出现钻石级，此时商店大量刷出核心卡，低级卡概率骤降。
- 第 5 天左右通常面临**阵容转型**——投入大量经济确定终局构筑，之后经济重新累积用于购买强力高阶卡。

### 3. 卡牌功能定位（构筑思想）

卡牌大致分为四类"端口"，构筑围绕核心牌（终端牌）进行有序排列组合，追求 1+1>2 的涌现式联动：

- **输出端**：武器、灼烧、剧毒、暴击等造成伤害的卡。
- **运转端**：加速、减速、充能、冰冻等控制冷却节奏的卡。
- **防御端**：护盾、治疗、回复等生存卡。
- **经济卡**：产出金币、提升物品价值的卡。

### 4. 战斗机制

- 战斗全自动进行：双方棋盘上的卡牌各自**读冷却条**，冷却满即触发攻击或技能，**先清空对方生命值者获胜**。
- 博弈点不仅在伤害数值，更在于**加速己方冷却、减速/冰冻敌方冷却**的节奏控制。

### 5. 常见关键词

| 关键词 | 效果 |
|---|---|
| 加速（Haste） | 物品冷却以 2 倍速度推进，持续指定秒数 |
| 减速（Slow） | 物品冷却以 1/2 速度推进，持续指定秒数 |
| 充能（Charge） | 立即推进物品冷却指定秒数 |
| 冰冻（Freeze） | 暂停物品冷却指定秒数 |
| 灼烧（Burn） | 持续伤害，每跳从 2 倍数值起逐渐递减；护盾可减免 50% |
| 剧毒（Poison） | 持续伤害，每跳 1 点，不随时间衰减，且无视护盾 |
| 护盾（Shield） | 主生命值之外的额外血条（马克没有护盾卡） |
| 暴击（Crit） | 按概率使物品效果翻倍 |
| 弹药（Ammo） | 攻击次数有限，需要装填手段 |
| 多重施法（Multicast） | 每次使用触发多次 |
| 摧毁（Destroy） | 使一件物品在本场战斗中消失 |
| 吸血（Lifesteal） | 按造成伤害回血（先扣对方护盾） |
| 回血/再生（Regen） | 随时间回血，是剧毒的直接对策 |
| 飞行（Flying） | 受到的冰冻/减速效果减半（斯黛尔、杜利专属） |
| 变形（Transform） | 将物品变为同大小同稀有度的另一件（马克专属机制） |
| 价值（Value） | 物品越贵越强（皮格马利翁专属机制） |
| 战利品（Loot） | 出售时给其他物品提供加成 |

### 6. 附魔系统

- 附魔可为一张卡直接附加额外关键词，共 **8 种**：灼烧、剧毒、冰冻、加速、减速、护盾、**辉耀**（防止被减速/冰冻/摧毁）、**黑曜石**（双倍伤害）。
- 每张卡同一时间只能有一个附魔。附魔能让输出卡兼任运转端、让运转卡变成输出端，是重要的构筑变量。
- 常规只有马克能用试剂/催化剂主动附魔，其他英雄需等待特殊事件。

### 7. 跨角色卡牌获取

- 每个角色有百余种独立卡牌，但游戏内存在**钻石级事件**可向其他角色购买卡牌；打野怪也有概率掉落野怪的卡牌。
- 由于所有卡牌都按"端口"思想设计，跨来源卡牌可以互通使用，常常左右最终构筑方向。

## 六、策略要点速览

1. **前期求生存与经济**：开局低品质卡多为辅助/经济卡，目标是赢下前两天并为后期攒经济。
2. **中期定方向**：第 5 天左右根据拿到的核心卡决定构筑方向，果断转型。
3. **后期拼上限**：围绕终端牌补齐运转端与防御端，利用附魔和跨角色卡牌拉高上限。
4. **背包管理**：格子有限，物品大小、摆放位置（不少卡影响相邻物品）都要精打细算。
5. **经济规划**：熟悉商店物品价格，为关键核心卡预留金币；判断何时白嫖事件、何时进店消费。

## 七、世界观与美术

游戏以"集市"（Bazaar）为世界观舞台，融合奇幻与科技元素。卡牌设计大量取材于生活中熟悉的事物——工程师的热气球与点火枪、海盗的水产武器等，既降低理解成本，也让构筑逻辑自洽。美式卡通画风配合火焰、冰冻等战斗特效，视觉表现精致。
