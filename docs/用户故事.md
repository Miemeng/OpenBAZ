# 用户故事

## 用户故事 1：模拟模式 —— 拖拽摆盘进行对战模拟

**作为** 玩家，
**我希望** 打开游戏后加载内置基础卡牌，进入模拟模式，浏览卡牌列表并把自己想要的卡牌拖到双方场上进行模拟对战，
**从而** 快速验证阵容搭配和卡牌强度。

### 场景描述

打开游戏本体后，加载内置的基础卡牌。进入模拟模式，玩家寻找并拖动自己想要的卡牌完成摆盘，然后开始模拟。界面内：

- 敌我双方各有血量条，血量归零判负；
- 技能以圆形图标显示，置于头像两侧；
- 卡牌在敌我双方场上各占一行，卡牌分三种尺寸（小 / 中 / 大）、四种品质（青铜 / 白银 / 黄金 / 钻石）；
- 支持自定义品阶和卡牌框（表现层资源，不影响战斗逻辑）。

### 验收标准

- [ ] 进入模拟模式时，内置基础卡包已自动加载，卡牌列表可按品阶/标签筛选
- [ ] 拖拽卡牌到己方/敌方一行 10 格的任意合法位置，大/中卡按规则占据多个连续格
- [ ] 点击开始后引擎跑出确定性结果，界面可回放整场战斗（血量变化、技能触发时机）
- [ ] 卡牌按品阶颜色和卡框渲染，自定义品阶/卡框可正确显示

## 用户故事 2：自定义模式 —— YAML 模板创建卡牌

**作为** 创作者玩家，
**我希望** 在自定义模式中创建卡包和卡牌，卡牌先生成为模板 YAML 放到草稿文件夹，我用 YAML 编辑好后即可测试，
**从而** 在不写游戏代码的前提下制作自己的卡牌。

### 场景描述

打开游戏本体后，进入自定义模式。自定义模式支持创建卡包和创建卡牌。创建卡牌时，客户端生成模板 YAML 文件置于草稿文件夹（`drafts/`）。玩家使用 YAML 文件编辑卡牌定义（本阶段暂不支持直接用中文自然语言创建，即 L1 语法）。编辑保存后进行测试，游戏热加载该卡牌并给出校验结果与效果回显。

### 验收标准

- [ ] 可创建卡包（生成 `packs/<pack_id>/pack.yml` 骨架）
- [ ] 创建卡牌时生成带注释说明的模板 YAML 到 `drafts/`
- [ ] 编辑保存后自动热加载：校验通过则进入可测试状态，失败则提示文件、行号与错误原因，不影响已加载的旧版本
- [ ] 测试时可把草稿卡牌加入模拟模式的阵容进行对战
- [ ] 测试通过后可选择将卡牌移入正式卡包

## 用户故事 3：模拟模式 —— 加载外部卡包进行模拟

**作为** 玩家，
**我希望** 在模拟模式中加载预先下载好的卡牌或卡包，然后进行模拟，
**从而** 体验其他创作者制作的卡牌内容。

### 验收标准

- [ ] 支持导入卡包文件/文件夹，校验通过后加入卡牌库
- [ ] 导入的卡牌与内置卡牌同样参与模拟模式的选卡与对战
- [ ] 导入卡包的版本与依赖（若引用其他卡包的卡牌）有明确校验与提示

## 关键规则决议（2026-10-01 补充）

- 时间模型：**tick 制，0.2 秒/tick**
- 格子排布：**每人一行 10 格**；相邻 = 同侧格子索引相邻
- 卡牌与血量：**卡牌无血量**，移除卡牌只能靠明确效果；**玩家血量是胜负条件**，效果直接作用于对手或自己
- 多被动结算顺序：**被动自带优先级，数值大先触发；同优先级入场早的先；入场时间也相同则本家优先**
