# 参数表设计 — 触发器事件参数（varN）规范

> 版本：v0.3（移除 tick 时机词版）
> 对应：《规则说明书》v0.10 §6.1 触发器结构、§8.2 表达式；时机词全集见《时机表.md》
> 读者：策划、开发者、卡牌创作者（DIY 玩家）

## 1. 目的与定位

触发器 = 时机词（event）+ **可选参数（varN）** + 可选条件（condition）+ 动作列表（actions）。

本文档定义每个时机词广播时携带的**命名参数集**，供触发器的 `condition` 与 `actions` 中的表达式引用。参数表与时机表同为封闭词典：引用未定义的参数在校验阶段直接报错。

## 2. 引用语法

| 形态 | 写法 | 说明 |
|------|------|------|
| 标量参数 | `{ var: amount }` | 引用本次事件携带的数值参数 |
| 对象属性 | `{ var: card.atk }` | 对 `cardRef` / `playerRef` 类型参数继续取属性，属性集合与《规则说明书》§8.3 封闭引用表一致 |

## 3. 参数类型

| 类型 | 含义 |
|------|------|
| `number` | 数值 |
| `cardRef` | 卡牌实例引用（可取 atk / speed / slotIndex / multicast 等属性） |
| `playerRef` | 玩家引用（可取 hp / maxHp / hpPct / shield / burn / poison / regen 等属性） |
| `side` | 阵营标记（`own` / `enemy`） |

## 4. 通用参数（所有事件均携带）

| 参数 | 类型 | 含义 |
|------|------|------|
| `eventName` | string | 时机词名称 |
| `tick` | number | 事件发生的 tick 序号 |
| `source` | cardRef / null | 事件来源卡（技能触发时为 null） |
| `sourceSide` | side | 事件来源方阵营 |

## 5. 各时机词参数表

| 时机词 | 专属参数 |
|--------|----------|
| `battleStart` | —（仅通用参数） |
| `battleEnd` | `winner`（side / `draw`）、`ownHp`、`enemyHp`（number） |
| `beforeAction` | `card`（cardRef）、`slotIndex`（number） |
| `afterAction` | `card`（cardRef）、`slotIndex`（number）、`damageDealt`（number，本次行动实际造成的伤害） |
| `onPlayerDamaged` | `player`（playerRef）、`amount`（number，实际扣血量）、`shieldAbsorbed`（number，护盾抵扣量）、`damageType`（normal / burn / poison） |
| `onCardDamaged` | `card`（cardRef）、`amount`（number，声明伤害值，卡牌无实际损失） |
| `onPlayerHealed` | `player`（playerRef）、`amount`（number，实际恢复量，可为 0）、`cleansedBurn`（number）、`cleansedPoison`（number） |
| `onShieldGained` | `player`（playerRef）、`amount`（number） |
| `onShieldBroken` | `player`（playerRef）、`overflow`（number，击穿护盾后溢出到血量的伤害） |
| `onCardDestroyed` | `card`（cardRef）、`slotIndex`（number） |
| `onCardRepaired` | `card`（cardRef）、`slotIndex`（number） |
| `onCardFrozen` / `onCardHasted` / `onCardSlowed` / `onCardCharged` | `card`（cardRef）、`duration?`（number，冰冻 / 加速 / 减速）、`amount?`（number，充能推进秒数） |
| `onBurnTick` | `player`（playerRef）、`stacks`（number，结算前层数）、`damage`（number，本次跳伤实际伤害） |
| `onPoisonTick` | `player`（playerRef）、`stacks`（number）、`damage`（number） |
| `onRegenTick` | `player`（playerRef）、`stacks`（number）、`heal`（number） |

## 6. 示例

```yaml
# 己方玩家单次受伤超过 50 时，对敌方玩家造成等量伤害
trigger:
  event: onPlayerDamaged
  condition:
    all:
      - { cmp: eq, left: { var: player }, right: { ref: ownPlayer } }
      - { cmp: gt, left: { var: amount }, right: 50 }
  actions:
    - do: dealDamage
      target: enemyPlayer
      amount: { var: amount }
```

```yaml
# 相邻己方卡牌主动行动后，自身获得 5 点攻击（可叠 3 层）
trigger:
  event: afterAction
  condition:
    all:
      - { cmp: eq, left: { var: sourceSide }, right: own }
      - { cmp: neq, left: { var: card }, right: { ref: self } }
      - { cmp: gt, left: { var: slotIndex }, right: { add: [ { ref: self.slotIndex }, 1 ] } }
  actions:
    - do: gainStat
      stat: atk
      amount: 5
      stackLimit: 3
      target: { pick: self }
```

## 7. 校验规则

1. `{ var: ... }` 只能引用当前 `event` 参数表中已定义的参数名，否则校验报错。
2. `cardRef` / `playerRef` 的属性访问仅允许 §8.3 封闭引用表中的属性路径。
3. 参数为只读快照：动作执行期间修改场上状态不回写已入栈触发记录中的参数值。
