# 时机表 — 触发器时机词全集（封闭词典）

> 版本：v0.5（移除 tick 时机词版）
> 对应：《规则说明书》v0.10 §6、§7；参数定义详见《参数表设计.md》
> 读者：策划、开发者、卡牌创作者（DIY 玩家）

## 使用约定

1. 本表为**封闭词典**：卡面 / 技能书写触发器时只能使用表内时机词，校验阶段拒绝表外取值。
2. 新增时机词须先修订本表并登记版本，再按《规则说明书》§6 流程增补进模拟器。
3. 所有时机词统一受《规则说明书》§6.3 约束：事件发生后 0.01s 起允许结算，同一触发器每 tick 最多结算一次，多余次数顺延。
4. 状态标注：✅ 已决议可实现；❓ 暂定开放，待评审；🚫 内部时机，不开放给卡面书写。

---

## A. 战斗生命周期

| 时机词 | 触发时机 | 状态 |
|--------|----------|------|
| `battleStart` | 摆盘完成、首个 tick 之前，广播一次 | ✅ |
| `battleEnd` | 胜负判定完成后，广播一次 | ✅ |

## B. 行动类

| 时机词 | 触发时机 | 状态 |
|--------|----------|------|
| `beforeAction` | 任意卡牌执行主动行动之前 | ✅ |
| `afterAction` | 任意卡牌主动行动完成之后（别名 `onAction`，二者等价，卡面统一写 `afterAction`） | ✅ |

> **主动效果没有时机词**：`kind: active` 的条目挂靠在本卡唯一的行动条上，行动条充满即随主动行动按书写顺序结算（规则 §5）；其计数变体 `everyN` 是主动效果的**字段**而非时机词，不收录本表。

## C. 伤害 / 治疗 / 护盾

| 时机词 | 触发时机 | 状态 |
|--------|----------|------|
| `onPlayerDamaged` | 任一玩家受到实际伤害结算后（含灼烧 / 剧毒跳伤） | ✅ |
| `onCardDamaged` | 卡牌被 `dealDamage` 指定后（卡牌无血量，仅作联动时机） | ✅ |
| `onPlayerHealed` | 任一玩家治疗结算后（满血治疗也广播，实际恢复量可为 0） | ✅ |
| `onShieldGained` | 任一玩家获得护盾后 | ✅ |
| `onShieldBroken` | 任一玩家护盾被完全击穿后（护盾池从 >0 变为 0） | ✅ |

## D. 卡牌状态

> 游戏内无召唤物，所有卡牌战前布置完成，战斗中无进场事件（v0.4）。

| 时机词 | 触发时机 | 状态 |
|--------|----------|------|
| `onCardDestroyed` | 卡牌被 `destroy` 失效后 | ✅ |
| `onCardRepaired` | 卡牌被修复（repair）后 | ✅ |
| `onCardFrozen` / `onCardHasted` / `onCardSlowed` / `onCardCharged` | 卡牌被施加冰冻 / 加速 / 减速 / 充能后 | ✅ v0.4 决议开放 |

## E. 持续效果跳变（burn / poison / regen）

| 时机词 | 触发时机 | 状态 |
|--------|----------|------|
| `onBurnTick` | 灼烧每 0.5s 结算跳伤时（含护盾抵扣与层数衰减 20%） | ✅ |
| `onPoisonTick` | 剧毒每 1s 结算跳伤时（无视护盾，不衰减） | ✅ |
| `onRegenTick` | 再生每 1s 结算回血时 | ✅ |

## F. 内部时机（不开放书写）

> 当前无内部时机词。主动效果挂靠在本卡唯一的行动条上，无"冷却到期"类内部时机（原 `cooldownReady` 已随独立 cooldown 废除，见 v0.3 变更记录）。
