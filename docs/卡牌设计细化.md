# 卡牌设计细化（卡面与悬浮细节窗口 v3.0）

> 版本：v3.0（2026-10-03，单一主动条 + cooldown 秒制版，取代 v2.0）
> 依据：《规则说明书 v0.10》《卡牌模拟器框架设计 v0.14》《YAML数据格式规范 v0.7》（框架 v0.13 仅新增 §2.5 仓库形态与运行边界、v0.14 仅新增 §2.5.3 工具链决策，均不影响本文档表现层内容）
> 定位：表现层设计文档，配合《卡牌模拟器框架设计》使用；只规定"怎么显示"，不改变引擎逻辑
> 适用范围：模拟模式（摆盘、对战中、回放）与自定义模式的"效果回显"

---

## 1. 设计目标

1. **场上只保留一个核心读数**：卡面主体是一根**纵向百分比进度条**（= 唯一行动条 gauge），从最低端向上填充，到达顶端即执行主动行动。
2. **主动效果挂靠唯一行动条**：主动效果无独立冷却——"冷却"就是行动条本身（充满周期 = `cooldown`（秒）× cdp ÷ 100 ÷ 速度倍率，规则 §5）；CD 标注与完整效果描述**不在卡面展开**，统一放入悬浮窗口。
3. **信息分级**：卡面 = 进度 + 核心数字；悬浮窗 = 数值行 + 行动条读数 + 逐条效果描述。
4. **与引擎同源**：所有显示内容由解析后的 `CardDef` 渲染生成，自定义卡牌同样可读。

---

## 2. 场上卡面规范

| 尺寸 | 宽 | 高|
|------|----------|---------|
| 小（small） | 200px | 300px |
| 中（medium） | 400px | 300px |
| 大（large） | 600px | 300px |

### 2.1 主进度条：行动条百分比

卡面主进度条为一根**纵向进度条**（横贯卡牌的横线，和卡牌边框呈"日"字形，底 = 0%，顶 = 100%）：

- 每张卡**至多一根进度条**；`cooldown = -1` 的纯被动物品无行动条，进度条不显示。
- 进度条百分比 = 行动条充满进度（受加速 ×2 / 减速 ×0.5 / 冰冻 = 0 与 `cdp` 实时影响）。
- 百分比数字规则：显示 `行动 67%`；空间充足时附预计剩余 `≈1.4s`（= 当前充满周期 × 剩余比例，随状态实时变化）。

### 2.2 三种尺寸的信息量

| 尺寸 | 占用格数 | 卡面显示内容 |
|------|----------|--------------|
| 小（small） | 1 | 主进度条（4px 细条，不标数字）+ 攻击数值 + 品阶色条 |
| 中（medium） | 2 | 上述 + 百分比数字 + 卡牌名称（截断）+ 状态角标（加速/减速/冰冻/失效） |
| 大（large） | 3 | 上述 + **被动触发计数条**（见 4.3）+ 层数数字 + 主动/被动图标标记 + multicast `*N` 标注 |

统一规则：

- 数值显示在卡牌最上方一行位置，根据其数值内容不同，设置不同的背景色。
- 品阶颜色来自 `rarities.yml`，自定义品阶/卡框同样生效。
- **卡面上不显示** 行动条秒数标注与效果描述文字——它们只出现在悬浮窗口。
- `destroyed` 卡牌：进度条停格、卡面灰暗，仍占位（失效 ≠ 离场，规则 §9.7）。

## 3. 主动效果设计规范（单一主动条）

主动效果一律**挂靠在唯一行动条**上（规范 3.1，主动效果无 trigger/cooldown/priority 字段）：

```yaml
abilities:
  - id: 1
    kind: active
    # everyN: 3            # 选填：仅本卡第 3、6、9… 次主动行动时结算（唯一计数变体）
    actions:
      - do: dealDamage
        target: { pick: randomEnemyCard }
        amount: self.atk
```

- **计时**：行动条充满周期 = `cooldown`（秒，卡面顶层必填）× (`cdp` ÷ 100) ÷ 速度倍率；充满 → 执行主动行动 = 挂靠主动效果按**书写顺序**依次结算（**无内置普攻**，规则 §1）→ 全部结算完重新累积（规则 §5）。
- **多个主动效果**：共用同一行动条，无独立冷却；悬浮窗按书写顺序逐条列出。
- **计数变体**：`everyN` 为唯一计数变体（引擎以 `actionCount` 计数），悬浮窗标注 `每 N 次行动` + 当前计数 `2/3`。
- **多重触发**：`multicast`（缺省 1）= 行动条充满后主动行动连续执行 N 次，卡面标注 `*N`、悬浮窗标明。
- 时间换算：秒 ↔ tick 按 `0.2s/tick`；卡面与悬浮窗一律以**秒**显示。

## 4. 悬浮细节窗口

### 4.1 触发与定位

- **移入即显**：鼠标移动到卡牌上立即弹出（无刻意延迟），移出隐藏；触屏设备点按 = 打开，点空白 = 关闭。
- **贴边翻转**：默认出现在光标右下方，距视口边缘不足窗口宽高时自动翻转到左上方。
- **固定（Pin）**：单击卡面固定窗口；再次单击卡面或点击窗口外关闭。
- **对战中**：窗口内行动条读数、层数、buff 数值每秒随战斗状态刷新，窗口位置不跳动。

### 4.2 整体布局

固定宽度 360px，高度自适应，超过 480px 内部滚动。四区域自上而下：**数值行 → 行动条读数条 → 效果区（主动在上、被动在下）→ 底部信息条**。

```
┌──────────────────────────────────────────────────┐
│ ⚔ 烬狼                                    [黄金] │
├────────────┬─────────────────────────────────────┤
│            │  攻击 45 · 速度 1.0 · 灼烧 15        │  ← 数值行（最上方）
│            │ ┌─────────────────────────────────┐ │
│            │ │ 行动条 3.0s · 当前 67%           │ │  ← 行动条读数条
│            │ └─────────────────────────────────┘ │
│            │ ┌─────────────────────────────────┐ │
│            │ │【主动】                          │ │
│            │ │ · 对随机敌方卡牌造成 45 点伤害   │ │
│            │ └─────────────────────────────────┘ │
│            │ ┌─────────────────────────────────┐ │
│            │ │【被动 · 优先级 10】              │ │
│            │ │ 敌方玩家受伤时                    │ │
│            │ │ · 自身攻击 +20%                  │ │
│            │ │ 触发计数 ▓▓▓░░ 3/5 层            │ │
│            │ └─────────────────────────────────┘ │
├────────────┴─────────────────────────────────────┤
│ 野兽 · 火系         占用 2 格 · v1                 │
└──────────────────────────────────────────────────┘
```

### 4.3 区域规则

**① 头部**：卡牌名称 + 品阶徽章（颜色取自 `rarities.yml`）；自定义卡框时窗口边框同步渲染。

**② 数值行（最上方）**：卡牌本身数值汇总，图标 + 数值横向排列，顺序固定为 攻击 → 速度 → 护盾 → 治疗 → 灼烧 → 剧毒 → 再生。详见第 5 节。

**③ 行动条读数条**：仅在 `cooldown ≠ -1` 时渲染。显示充满周期秒数与当前进度百分比；就绪（充满当 tick）时显示 `就绪` 并高亮。纯被动卡无此条。

**④ 效果区**：每个主动 / 被动效果各一条卡片，格式见第 7 节。**主动效果无独立 CD 单元**（冷却就是行动条，读数在 ③）；有 `everyN` 的主动卡片附小字计数 `2/3`。被动卡片格式为「【被动 · 优先级 N】触发时机 → 效果列表」，有计数设计的被动在卡片底部附**触发计数条**（`▓▓▓░░ 3/5 层`），与卡面细条同源同步。

**⑤ 底部信息条**：标签（tags）、占用格数、版本号（`version`）。

## 5. 数值行汇总规则（卡面最上方）

由引擎从 `CardDef.stats` 开放数值表自动汇总，只写这张卡自己的数值；**仅显示约定字段**，自定义字段不进数值行。

| 显示项 | 背景颜色 | 来源 | 取值规则 |
|--------|------|------|----------|
| 攻击 | 红 | `stats.atk` | 攻击数值，战斗/预览中显示实时值（含 buff）；**不内置普攻**（规则 §1），要造成伤害须由主动/被动效果显式声明 `dealDamage`（引用 `{ ref: self.atk }`） |
| 速度 | 蓝 | `stats.speed` | 缺省 1 不显示 |
| 护盾 | 黄 | `stats.shd` | 护盾量，为玩家施加护盾 |
| 治疗 | 绿 | `stats.hel` | 治疗量，为玩家恢复血量 |
| 灼烧 | 橙 | `stats.bur` | 灼烧层数，向玩家施加 DoT |
| 剧毒 | 深绿 | `stats.poi` | 剧毒层数，向玩家施加 DoT（无视护盾） |
| 再生 | 浅绿 | `stats.reg` | 再生层数，为玩家施加 HoT |

- **静态可求值**（纯数字）：直接显示，如 `攻击 45`。
- **表达式数值**（如 `{ mul: [self.atk, 0.2] }`）：能求值则替换为实时数字，战斗中的额外 buff 直接求值显示。
- **没有某项就不写**：stats 未定义或值为 0 的项不渲染。
- 其他约定字段（`has` / `sol` / `fre` / `chg` / `cdp`）不显示在数值行，仅在效果描述文本中以秒数/百分比呈现。

## 6. 行动条标注规则（悬浮窗读数条）

- **每张卡至多一个行动条读数条**（③ 区），纯被动卡（`cooldown = -1`）不渲染。
- 读数内容：
  - 冷却中（累积中）：`行动条 {充满周期}s · 当前 {进度}%`，充满周期随加速/减速/冰冻/cdp 实时变化；
  - 就绪（充满当 tick）：显示 `就绪` 并高亮发光；
  - 冰冻中：雪花图标 + `冰冻`，进度冻结显示。
- **主动效果不再有独立 CD 单元**（v3.0 起废除 v2.0 的"左 CD、右效果"版式）；`everyN` 计数以小字附在其效果卡片内。

## 7. 效果文本渲染模板（L2 → 显示文案）

由引擎按词典逐条生成，与框架设计 §9 回显格式一致；单行放不下时折行，不截断。

**主动效果模板**：

```
【主动】行动条充满时（按书写顺序依次触发）
· {动作1}
· {动作2}
```

`everyN` 变体：`【主动 · 每 3 次行动】` + 小字计数 `当前 2/3`。
`multicast` 变体：标题附 `×2`，注明"充满后连续执行 2 次"。

**被动技模板**：

```
【被动 · 优先级 {N}】{触发时机}
· {动作1}
触发计数 ▓▓▓░░ {当前}/{上限} 层     ← 仅计数型被动渲染
```

规则要点：

- 多条动作逐条以 `·` 分行列出。
- `priority` 缺省 5（未显式书写）时省略，显示【被动】。
- 触发时机按词表统一翻译（《时机表.md》）；条件以「若…」附加在时机后。

## 8. 边界情况

| 情况 | 处理 |
|------|------|
| 一张卡多个主动效果 | 挂靠同一行动条，充满后按书写顺序依次结算；进度条仍只有一根 |
| `everyN` 与 `multicast` 同卡 | 每次主动行动均检查 everyN；multicast 的 N 次行动各自计数 |
| 一张卡多个可计数被动 | 大卡并列多条计数细条；悬浮窗逐条附计数条 |
| 数值行超长（4 项以上） | 允许换行，图标 + 数值为一组不拆散 |
| 战斗中卡牌失效（destroy） | 进度条停格、卡面灰暗，仍占位；玩家依旧可以查看其功能（repair 后恢复渲染） |
| 纯被动卡（cooldown = -1） | 无进度条、无行动条读数条、无数值行以外的计时信息 |
| 自定义卡 YAML 非法但旧版本可用 | 按已注册旧版本渲染，窗口顶部加黄色"存在待修复的新版本"提示条 |
| 回放模式 | 窗口与卡面条均按当前回放 tick 的冻结状态渲染，不随真实时间刷新 |

## 9. 验收清单

- [ ] 卡面主体纵向进度条 = 唯一行动条，百分比与引擎 `actionGauge` 一致；
- [ ] 主动效果按单一主动条设计：`cooldown` 秒制（含 cdp），无独立冷却，多主动按书写顺序结算；
- [ ] 卡面不显示秒数标注与效果描述文字（它们只在悬浮窗出现）；
- [ ] 鼠标移入卡牌立即弹出悬浮窗，贴边翻转，单击固定，触屏点按可用；
- [ ] 悬浮窗最上方为数值行（攻击/速度/护盾/治疗/灼烧/剧毒/再生），来源为 stats 约定字段，战斗中 buff 实时变色；
- [ ] 行动条读数条显示充满周期秒数与当前进度，就绪高亮，冰冻雪花；纯被动卡无读数条；
- [ ] 主动效果卡片无独立 CD 单元；everyN 计数、multicast ×N 标注正确；
- [ ] 纯被动卡无任何行动条元素；计数型被动在卡面细条与悬浮窗计数条同步显示；
- [ ] 三种卡面尺寸信息量符合第 2.2 节，品阶/自定义卡框正确渲染；
- [ ] 自定义卡牌与内置卡牌走同一渲染管线，效果回显与悬浮窗文案一致。
