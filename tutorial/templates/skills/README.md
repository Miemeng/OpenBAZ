# 技能包模板（`skills/`）

一个技能包 = 一个目录，**目录名就是技能包 `id`**。把 `my_skill_pack/` 整个复制出去、改名，再改内容。

    my_skill_pack/
    ├── pack.yml              ← 包定义（id / name / version）
    ├── skills/<技能id>.yml   ← 每个技能一个文件，文件名 = 技能 id
    └── images/               ← 技能图标（png，文件名 = 技能 id）

要点：

- **技能包不规定英雄**：`pack.yml` **没有 `owner`** —— 它只是"技能合集"的分发单位。
- **技能归属写在自己文件里、且必填**：`heroes` 列表——可写多个英雄 id；**所有英雄可用写 `common`**；**所有英雄都不可用写 `sp`**（特殊情况下获得）。`common` / `sp` 是保留字，不是英雄 id；**该字段不可省略**。
- 技能和卡牌一样需要**购买 / 学习**，所以不随卡包分发；卡包的 `skills:` 字段自 v0.11 起作废。
- 卡包专属的 `owner` / `cards` / `rarities` 在技能包里**都不适用**。

字段定义见《YAML数据格式规范.md》§5.1 与 §4（`docs/` 内，暂不入库）。
