# 角色模板（`heroes/`）

> 目录名已由 RW 定为 **`heroes`**（早期的笔误 `heros` 已改）。

一个角色 = 一个目录，**目录名就是角色 `id`**。把 `my_hero/` 整个复制出去、改名，再改内容。

    my_hero/
    ├── my_hero.yml       ← 角色定义（最外层）
    ├── my_hero.png       ← 头像：与本文件同层、文件名 = 角色 id
    └── images/           ← 立绘等展示资源（png）

要点：

- `id` 同时是**归属锚点**：卡包 `pack.yml` 写 `owner: my_hero`，就表示那个包（连同包内所有卡牌）归属本角色。
- 角色文件**不列自己有哪些卡**（反向关系不在这里维护），只列 `owned_packs` / `owned_skill_packs` 两个清单。
- **技能归属不在这里**：由技能文件自己的 `heroes` 列表声明（**必填**：英雄 id 可多个 / `common` = 所有英雄可用 / `sp` = 都不可用）。
- 没有 `init_shield`（开局护盾已决议移除）。

字段定义见《YAML数据格式规范.md》§11（`docs/` 内，暂不入库）。
