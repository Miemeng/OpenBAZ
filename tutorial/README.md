# OpenBaz 新手入门

OpenBaz 是一个**异步自走棋卡牌模拟器**：你把两边的阵容摆好，程序按固定规则自动打完一局，还能逐帧回放。
卡牌、角色、卡包全部写在 **YAML 文本**里 —— 也就是说，**你可以自己加卡**。这套教程就是带你从"跑起来"走到"自己造一张卡"。

> **读者**：完全新手。会复制粘贴、会用记事本、知道 YAML 靠缩进分层次就够了。
> **不需要命令行、不需要装 Node.js** —— 全程只用桌面版和文件管理器。
> **范围**：只讲怎么 DIY（做卡 / 做包 / 摆盘 / 看报错），不讲规则推演。

## 0. 准备

| 你拿到的是 | 需要准备什么 |
|---|---|
| **安装包**（`OpenBaz Setup …exe` 或绿色版） | 双击安装 / 解压，然后打开 OpenBaz |
| 只有源码仓库 | 本教程不覆盖这种用法 —— 找发布者要安装包 |

第一次启动时，程序会自动把**基础包**放进你的数据目录（6 张卡 + 2 个角色），所以打开就能玩。

## 1. 认识界面

打开后顶部有两个标签：**卡牌库** 和 **摆盘**。

- 右上角有「**重载卡牌**」—— 你改完任何 YAML，点它就会重新读一遍。
- 顶栏还有一行统计：「卡包 N 个 · 卡牌 N 张 · 技能 N 个 · **问题 N 条**」。**"问题"是文件里的错误和提醒**，改文件后先看这里。

## 2. 卡牌库

- 左侧是卡牌列表，可以按 **搜索 / 品阶 / 标签 / 卡包** 筛选。
- 点任意一张卡，右侧显示卡图、品阶、大小、版本、来源包和**效果行**（"什么时候 ▶ 做什么"）。

**基础包 `base` 有 6 张卡**，先把它们认熟，后面做卡会照着写：

| id | 名字 | 品阶 · 大小 | 它干什么 |
|---|---|---|---|
| `plainSword` | 普通的剑 | 青铜 · 小 | 行动条满了砍一刀（5 点伤害） |
| `oldMachete` | 旧砍刀 | 青铜 · 小 | 砍一刀，并让自己攻击 +3 |
| `herbBottle` | 草药瓶 | 白银 · 中 | 给己方玩家治疗 20 |
| `shelter` | 庇护所 | 白银 · 中 | 给己方玩家 20 点护盾 |
| `maintainPack` | 维护包 | 黄金 · 中 | **纯光环**：己方全体卡牌攻击 +10、护盾 +10 |
| `treeHouse` | 树屋 | 钻石 · 大 | 主动给 40 点护盾；被动：有玩家受伤时回 5 点血 |

> 注意：草药瓶、庇护所这些卡**没有攻击属性**（YAML 里根本没写 `atk`），所以卡面不会显示"攻击"，攻击类加成也不会改变它们的任何效果。

## 3. 摆一局

1. 切到「**摆盘**」。屏幕上下两半分别是 **A 方** 和 **B 方**。
2. 每方先选角色：下拉框里默认是「（未选角色）」，可选 **盗贼**（300/300）或 **守卫**（350/400）。
3. 从最左边的卡源**点一张卡**，它会变成"手持"状态；再**点棋盘的格子**放下。
4. 同名卡可以放多张；点已经放好的卡 = 选中它（右侧「编辑栏」会展开），格子上的 ✕ = 收回。
5. 两边都放好卡后，点底部的「**开始对局**」。
6. **种子**留空 = 自动生成；想复现同一局，就把上次的种子填回去。

按钮点不动时，旁边会有一行「**还差：…**」，告诉你哪一边还缺东西（角色 / 卡 / 血量填错）。

## 4. 看回放与结算

对局是瞬间算完的，然后直接进回放：

- **空格** 播放 / 暂停；**← →** 逐帧；**Shift + ← →** 跳 10 帧；**Home / End** 首末帧；也可以拖动进度条跳转。
- 鼠标**悬停**看卡面，**单击**钉住（再点一次取消）。
- 右栏「本帧动作日志」= 这一帧到底发生了什么。
- 「**查看结算**」= 终局血量 / 护盾 + 完整日志；「**← 回到摆盘**」保留这一局，改完还能再跑。

## 5. 界面上的几个词

| 词 | 一句话解释 |
|---|---|
| **行动条** | 卡牌下面那根竖条。走满 = 这张卡出手一次 |
| **冷却**（`cooldown`） | 行动条走满需要的秒数，写在卡面上 |
| **触发帧** | 引擎每 **0.2 秒**统一结算一次，叫一帧（回放就是按帧走） |
| **触发器** | "某件事发生后自动执行"的被动，要写时机词（如"有玩家受伤时"） |
| **光环** | 这张卡在场期间，持续给一批目标加减数值，不占行动条 |
| **护盾** | 先挡伤害：普通伤害 1 点护盾抵 1 点 |
| **灼烧 / 剧毒 / 再生** | 玩家身上的持续效果（按秒结算），不是卡牌状态 |
| **种子** | 随机数种子。同一个种子 + 同一套阵容 = 完全一样的一局 |
| **卡包**（内容包，`pack`） | 一个文件夹，里面装卡牌、技能、角色、图片 |

## 7. 出错了怎么办

1. 先点一次「**重载卡牌**」，看顶栏的「**问题 N 条**」。
2. 有问题时，下方会列出每一条：`[error] 错误码  文件:行  说明`。**只有 `[error]` 会让那张卡 / 那个包加载失败**；`[warn]` 会照常执行、`[note]` 只是提醒。
3. 按错误码去 **[troubleshooting.md](troubleshooting.md)** 查"怎么改"。
4. 你的卡没出现在卡牌库？先按 [troubleshooting.md](troubleshooting.md) 第 5 节逐条对一遍（十有八九是文件名或清单没对上）。
