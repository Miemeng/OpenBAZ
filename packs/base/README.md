# 基础规则包（`packs/base/`）

**定位**：基础规则与数值的**权威落点**，随程序分发。

| 项 | 说明 |
|----|------|
| **本包放什么** | 目前只有 `rarities.yml`**品阶**（`id` / `name` / `color` / `frame`）与**卡牌价值**（`value` / `prize`）的默认表 |
| **本包不放什么** | 不含 `cards/` · `skills/` · `heroes/` · `images/` |
| **与 `test` 的区别** | `test`（ 前叫 `core`）是**内置机制覆盖包** —— 每种原语 / 状态 / 光环 / 技能形态各一张卡，数值都是占位、随时可调；`base` 是**基础规则**，改它要慎重 |
| **引擎兜底** | 品阶没写 `value` 时，引擎按内置表兜底（bronze 1 / silver 3 / gold 8 / diamond 20），**防止本包被改动后经济崩掉** |
| **价值怎么用** | 卡面 `stats.value` 缺省时按**当前品阶**的 `value` 初始化；`prize` 不写则等于 `value`（模拟模式战斗内不变价） |
| **合成链限制** | `upgrade` 链**暂时只允许内置四档**；自定义品阶仍可登记（供卡牌 `rarity` 引用）但不得进链 |
