# 基础内容包（`packs/base/`）

**定位**：基础内容与数值的**权威落点**，随程序分发；**桌面版首次启动装的就是这一包**。

| 项 | 说明 |
|----|------|
| **本包放什么** | ① `rarities.yml` **品阶 + 卡牌价值**（`id` / `name` / `color` / `frame` / `value` / `prize`）；② `cards/` **6 张基础卡**；③ `heroes/` **2 个基础角色**；④ `images/` 卡图与头像 |
| **6 张基础卡** | `plainSword` 普通的剑（青铜·小，主动伤害）· `oldMachete` 旧砍刀（青铜·小，伤害 + 自身攻击 +3）· `herbBottle` 草药瓶（白银·中，治疗）· `shelter` 庇护所（白银·中，护盾）· `maintainPack` 维护包（黄金·中，**纯光环**：己方全体 攻击+10 / 护盾+10）· `treeHouse` 树屋（钻石·大，主动护盾 + 被动受伤回血） |
| **2 个基础角色** | `thief` 盗贼（300 / 300）· `guard` 守卫（350 / 400） |
| **内容口径** | 这 6 张卡**只用"无触发器 / 单一触发器"**：附魔、`multicast`、`everyN`、条件表达式、查询对象一律不出现（那些在 `packs/test` 里当机制覆盖） |
| **与 `test` 的区别** | `test` 是**内置机制覆盖包**（每种原语 / 状态 / 光环各一张卡，数值占位、随时可调，**不随安装包分发**）；`base` 是**基础内容**，改它要慎重 |
| **引擎兜底** | 品阶没写 `value` 时，引擎按内置表兜底（bronze 1 / silver 2 / gold 4 / diamond 8），防止本包被改动后经济崩掉 |
| **价值怎么用** | 卡面 `stats.value` 缺省时按**当前品阶**的 `value` 初始化；`prize` 不写则等于 `value` |
| **合成链限制** | `upgrade` 链**暂时只允许内置四档**；自定义品阶仍可登记（供卡牌 `rarity` 引用）但不得进链 |
| **素材落点** | 卡图 `images/cards/<card_id>.png` · 头像 `images/heroes/<hero_id>/avatar.png` · 卡框 `images/frames/<frame_id>/card_frame.png`；**缺图不报错**（客户端回落首字色块 / 品阶色） |

> 规则口径见《规则说明书.md》；字段定义见《YAML 数据格式规范.md》。
